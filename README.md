# arition's OpenWrt / LEDE repository

Packages for OpenWrt, including `vlmcsd` and its LuCI interface `luci-app-vlmcsd`.

## OpenWrt 25.12

OpenWrt 25.12 uses APK packages. Follow the
[OpenWrt 25.12 installation instructions](./openwrt-25.12/) to import the
[APK public key](./arition-repo.pem), add the repository for your architecture,
and install the packages.

The old opkg feed configuration and usign key are for earlier OpenWrt releases.
Use the repository that matches your installed OpenWrt release.
